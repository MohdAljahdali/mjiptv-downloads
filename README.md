# MJ IPTV downloads

Installation files for MJ IPTV on Android and Android TV. The application source repository is private.

[Download the latest Android APK](https://github.com/MohdAljahdali/mjiptv-downloads/releases/latest/download/MJ-IPTV-Android.apk)

## Install with Downloader

1. Open Downloader on your Android TV or Google TV.
2. Enter the direct APK download link above, or create its numeric code with [AFTVnews URL Shortener](https://go.aftvnews.com/).
3. Download the APK, allow Downloader to install applications if Android asks, and select Install.

Requires Android 7.0 or newer. The universal APK includes arm64-v8a, armeabi-v7a, and x86_64.
